# SQL-Database-Architecture-Externship-with-Breaking-Games

**Role:** SQL & Database Architecture Externship
**Company:** [Breaking Games](https://breakinggames.com), an indie board game publisher in Netcong, NJ
**Tools:** SQLite, DB Browser for SQLite, SQL, Claude (AI co-pilot), Google Docs

## Overview

Breaking Games' data lived in six disconnected spreadsheet exports (Shopify sales, orders, checkouts, referral traffic, and Meta Ads campaigns and ad sets) with no shared IDs between them. The team couldn't answer basic questions: which games actually make money, whether the Meta ad spend worked, or how many "customers" were real.

Over this externship I designed a relational database on top of those exports, cleaned and connected the data, and delivered three decision-ready recommendations: a holiday reprint plan, a Q4 ad budget reallocation, and a cart-abandonment analysis.
